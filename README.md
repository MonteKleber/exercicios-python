# 🐍 Exercícios de Python

Repositório criado para registrar minha evolução nos estudos de Python e lógica de programação.

Os exercícios estão organizados por níveis de dificuldade e têm como objetivo praticar conceitos fundamentais da linguagem através da resolução de problemas.

## 📚 Conteúdos praticados

Até o momento, foram trabalhados conceitos como:

- Entrada e saída de dados
- Variáveis e tipos de dados
- Operadores aritméticos
- Estruturas condicionais (`if`, `elif` e `else`)
- Estruturas de repetição (`while`)
- Contadores e acumuladores
- Operador módulo (`%`)
- Lógica de programação
- Tratamento de casos especiais
